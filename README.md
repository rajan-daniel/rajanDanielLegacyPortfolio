# 🧑‍💻 Legacy Portfolio Website

## 📌 Preview
A personal developer portfolio built with Next.js and deployed on Vercel, created to showcase my projects, skills, and experience through a clean, responsive, and modern interface.

## 📖 About the Project
This was my original personal portfolio and served as my primary online presence before being replaced with a redesigned portfolio built in Framer.

A key part of this project was working with an existing codebase rather than starting from scratch, which required understanding its structure and making safe, targeted improvements without breaking functionality.

## 🚀 What I Learned
- Working with and modifying existing codebases
- Understanding unfamiliar project structure and flow
- Making safe, incremental changes in a production-style setup
- Deploying and managing projects on Vercel
- Improving UI/UX and responsiveness
- Structuring content for clear technical presentation

## 📍 The Process
I first explored the existing codebase to understand its structure and how the project was built. After getting familiar with it, I made careful improvements to the layout, content, and overall user experience.

Once the updates were complete, I deployed the site on Vercel. This project was originally connected to my GoDaddy domain before I later migrated the domain to my redesigned Framer portfolio. Final refinements focused on responsiveness, consistency, and overall polish.

## 🛠️ Technologies Used
- Next.js
- React
- Vercel
- HTML5
- CSS3
